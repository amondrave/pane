# Pane
### A fast, native and distraction-free editor for macOS.

> Open source.
> Native.
> Built by developers, for developers.

---

# Vision

Modern code editors have become incredibly powerful.

They are also becoming increasingly heavy.

Opening a simple JSON file, editing a configuration file or reviewing application logs should not require starting a full IDE.

Pane exists to bring back the feeling of instant editing.

Open.
Edit.
Save.
Done.

Nothing more.
Nothing less.

---

# The Problem

Today on macOS developers usually have two options.

## Option 1

Use VS Code.

Pros

- Great ecosystem
- Extensions
- LSP
- Git integration

Cons

- Slow startup
- High memory consumption
- Too many features for quick edits

---

## Option 2

Use TextEdit or Notes.

Pros

- Lightweight

Cons

- No syntax highlighting
- No regex
- No tabs
- No developer features

---

There is still a gap between both worlds.

Pane wants to fill it.

# AI

AI is optional.

Never mandatory.

Pane should remain fully functional without Internet.

When enabled, AI should help developers rather than replace them.
